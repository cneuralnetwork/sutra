Privacy

A short privacy note.

This page is about the website. The CLI’s data handling is documented in the repository, because it belongs next to the code that implements it.

Last updated: 6 November 2026

Website analytics

When analytics is enabled, this site uses Plausible, a privacy-focused analytics service. It records aggregate page views and referrers without cookies, without fingerprinting and without cross-site tracking. The site does not run advertising or third-party tracking scripts.

The site also links to GitHub. Following a link is a request to GitHub, and GitHub’s own privacy policy applies from that point.

The Sutra CLI

Sutra runs on your machine. Sessions, messages, tool calls, plans and usage are stored locally in SQLite under ~/.sutra/. The CLI does not push, publish or deploy on its own.

When you use a cloud model, the content the agent reads is sent to the model provider you configured. With a local model, inference stays on your machine. Read the security model for what is blocked, what is redacted, and what the sandbox does not cover.

No accounts, no forms

This website has no account system, newsletter, comment section or contact form. Project discussions happen on GitHub Issues.

Questions

If something here is unclear, open an issue in the repository. Security problems should be reported privately, as described in CONTRIBUTING.md.
