Why Sutra

A coding agent you can watch.

Most agents ask you to trust the result. Sutra shows the work: every read, edit, command and test on one thread, with the permissions, evidence and cost attached.

See every action

Reads, edits, commands and test runs appear on one thread as they happen. Every session is saved locally and can be replayed or exported as an audit report.

Audit and replay

Stay in charge

Three permission profiles, plus an OS sandbox on macOS and Linux. Repository content can describe conventions, but it cannot loosen the rules.

Permissions and sandbox

Know what it costs

Token usage, cache hits and estimated spend are tracked per request. A budget can pause the agent before it overspends, and local models report $0.

Cost and budgets

Verified, not just finished

A harness-owned finish gate checks each acceptance criterion against evidence recorded after the last edit, and marks what it cannot prove as unverified.

How it works

One loop, from question to evidence.

Sutra repeats a simple loop until the task is done, you stop it, or a limit is reached. Every turn ends in an explicit state: completed, failed, cancelled or over budget.

  1. 01

    Read

    Index the repository, read the likely files, and find symbols, callers and the tests that mention them.

  2. 02

    Plan

    Plan mode investigates read-only and records each step. Nothing changes until you approve the plan.

  3. 03

    Act

    Edits are previewed as diffs and written atomically. Commands run one at a time, inside the OS sandbox.

  4. 04

    Verify

    Run your test command, then check each acceptance criterion against evidence recorded after the last edit.

  5. 05

    Record

    Save the session locally. Replay it as a timeline, or export a Markdown or JSON audit report.

Commands run inside the OS sandbox. Edits are approval-gated. Nothing is left half-recorded.

Verification

Done should mean proven.

When the model stops calling tools, Sutra’s finish gate checks each acceptance criterion against checks recorded after the last edit. If the evidence is not there, the result is marked unverified — not done.

  • Evidence, not the model’s confidence
  • Counterexamples are re-run by the harness
  • Reviews can raise gaps, never pass a criterion

Quick start

Start with a task, not a config file.

You need Node.js 22.13 or newer on macOS or Linux. ripgrep is optional and makes search faster.

A first run is safe. Sutra asks before it changes a file or runs a command.

Bring a key or a local model. sutra init spots keys already in your environment and local servers that are running.

Questions

What to know before you start.

Sutra is an early preview. These are the answers that matter most before you point it at a repository.

Is Sutra free and open source?+

Yes. Sutra is released under the Apache License 2.0, including an explicit patent grant from contributors. You pay only your model provider when you use a cloud model. Local models are free.

Which models and providers can I use?+

DeepSeek is the tuned default. Sutra also works with OpenRouter, OpenAI, Anthropic, Google Gemini, xAI, Mistral, Groq, Cerebras, Together, Fireworks, DeepInfra, Moonshot, Z.AI, Qwen, SambaNova, Hugging Face, Vercel AI Gateway, any OpenAI-compatible server, and local models through Ollama, LM Studio, llama.cpp, vLLM and Jan.

Does Sutra send my code anywhere?+

The CLI sends the content the agent reads to the model provider you configure. With a local model, inference stays on your machine. Sutra stores sessions locally in SQLite and never pushes, publishes or deploys on its own. The security model explains exactly what is enforced.

What does the OS sandbox actually prevent?+

Commands run under your user account inside a sandbox. Writes are limited to the workspace, temp directories and package-manager caches; credential stores are hidden; outbound network traffic is blocked unless you approved that command as a network command. It is a strong second layer, not a virtual machine.

Does Sutra work on Windows?+

Not yet. macOS is the primary platform. Linux is supported, but the bubblewrap backend has not been tested on Linux yet. There is no Windows backend.

How is Sutra different from other coding agents?+

The harness owns the rules. Permissions and the sandbox cannot be changed by repository content, every action is recorded and replayable, and a finish gate refuses to call work done when the evidence is missing.

Are the benchmark numbers guarantees?+

No. The bundled suite is four small tasks. It measures whether a model handles Sutra’s tool loop reliably and roughly what each solved task costs; it is not a leaderboard of general coding ability. A harder held-out suite is on the roadmap.
